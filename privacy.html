Privacy Policy

Last updated: 2026-11-20

  • Who uses it. Bookkeeping is used only by its author for their own accounts.
  • Data accessed. With the read-only Gmail scope, it reads emails from the owner's banks and downloads their statement attachments. It does not read other people's data.
  • Where data is stored. Downloaded statements, parsed transactions and the OAuth token are stored only on the owner's own computer and the owner's private cloud storage.
  • Sharing. No data is sold, shared with, or transferred to any third party, and none is used for advertising or for training models.
  • Google API data. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Revoking access. Access can be revoked at any time at myaccount.google.com/permissions; deleting the local token and files removes all stored data.

繁體中文

本工具僅供作者本人使用。以 Gmail 唯讀權限讀取本人銀行寄來的帳單信件與附件；資料與授權 token 只存放在本人電腦與本人私有雲端空間，不出售、不分享、不提供給任何第三方，也不用於廣告或模型訓練。 從 Google API 取得的資料之使用遵守 Google API Services User Data Policy（含 Limited Use 規定）。 可隨時於 Google 帳戶「第三方存取權」撤銷授權，刪除本機 token 與檔案即刪除所有資料。
